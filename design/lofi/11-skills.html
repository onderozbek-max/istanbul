11 Survival Skills tree

Specs: game-design.md 8.1, 8.3 · business-plan.md 5.2, 6

  1. Owner request: "credits to improve skills". Three branches (Offense / Defense / Utility), five tiers, ranks 1-3, plus a capstone (Arda: Second Wind).
  2. Cost = tier × rank in Skill Credits. Credits: +2 per hero level, star chests, bosses, pass, and bundles (max 2 per week).
  3. Credits are the scarcest earnable resource by design, so each node feels like a decision.
  4. Kaan's tab is visible but locked ("joins at L30"): a teaser for the story.
  5. Node labels are placeholders; final nodes per game-design.md 8.3. Icons + text, never color only.
